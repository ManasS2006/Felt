The fork collapses three pillars into one learned object

Pillar 1 CFR Kept. Full-width CFR+ / DCFR, for low-noise targets. ✓ carried over
Pillar 2 Abstraction Replaced. The 13-bucket wall is gone; buckets only encode the net's input. → value network
Pillar 3 Subgame solving Replaced. The pillar the series never shipped. → continual re-solving + gadget

The four papers, and the job each one does

NIPS 2007 Regret Minimization in Games with Incomplete Information Zinkevich, Johanson, Bowling, Piccione The engine. Counterfactual regret; self-play minimization converges to Nash. Everything else sits on this.
arXiv:1303.4441 · 2014 Solving Imperfect Information Games Using Decomposition Burch, Johanson, Bowling The safety guarantee. Trunk / subgame split, and the T/F re-solve gadget that makes decomposition safe via opponent counterfactual values.
Science 2017 DeepStack: Expert-Level AI in Heads-Up No-Limit Poker Moravčík, Schmid, Burch, et al. The fork itself. Continual re-solving + depth-limited lookahead with a deep counterfactual value network at the leaves — no explicit abstraction.
AAAI 2023 · Deepsolver Don't Predict Counterfactual Values, Predict Expected Values Instead Wołosiuk, Świechowski, Mańdziuk The sharpening. Predict the smooth EV and multiply by the exact matchup — smaller, faster nets, ~30% lower encoding-error floor.
