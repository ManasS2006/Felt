Built with

C++ LibTorch / ATen CUDA portable fp32 feedforward value nets CFR-D Python & Go (earlier prototypes)

What it does

  • Re-solves each spot live instead of storing a blueprint — a river value net trained on solved river spots, then bootstrapped up into a turn net (DeepStack-style data generation).
  • Depth-limited continual re-solving (CFR-D) — the search only looks a few streets ahead; past the depth limit the value net stands in for solving to the end.
  • Ported the engine from CUDA to platform-agnostic C++/LibTorch, so the same solver runs with or without a dedicated GPU.
